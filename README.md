# Free Api Youtube Application

This is an web application to display thumbanails from youtube using the free api.

## Pages

1. Gallery Page

## Components

1. SideMenu
2. HeroSection
3. Thumbnail Gallery

## Tech Stack

1. React + Vite
2. Tailwind CSS

## Getting Started

1. Clone the repository

2. Install dependencies

```bash
npm install
```

3. Copy .env.example to .env

```bash
cp .env.example .env
```

4. Add VITE_API_BASE_URL=https://api.freeapi.app/api/v1 to .env (optional)

5. Run the app

```bash
npm run dev
```
